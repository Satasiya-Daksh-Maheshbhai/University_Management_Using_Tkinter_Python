# 🎓 University Management System (Tkinter + Python) 🖥️

🎓✨ Smart University Management System using Python &amp; Tkinter 🖥️💡! Effortlessly manage students 👨‍🎓 &amp; faculty 👩‍🏫 with add, search 🔍, delete ❌ &amp; display 📊 features. Includes secure admin login 🔐 and a clean, user-friendly GUI for smooth operations 🚀🔥
---

## ✨ Features

### 👨‍🎓 Student Management
- ➕ Add new students  
- 🔍 Search student by Roll Number  
- ❌ Delete student records  
- 📊 Display all students in tabular format  

### 👩‍🏫 Faculty Management
- ➕ Add new faculty  
- 🔍 Search faculty by ID  
- ❌ Delete faculty records  
- 📊 Display all faculty in table view  

### 🔐 Authentication
- Secure **Admin Login System**
- Prevents unauthorized access  

### 💡 UI/UX
- Clean & responsive Tkinter interface  
- Easy navigation panels  
- Interactive buttons and pop-up messages  

---

## ⚙️ Technologies Used
- 🐍 Python  
- 🖼️ Tkinter (GUI)  
- 📦 ttk (Treeview for tables)  

---

## 🚀 How to Run the Project

1. Make sure Python is installed on your system  
2. Download or clone this repository  
3. Open terminal / command prompt  
4. Run the following command:

```bash
python UniversityManagement.py

```
